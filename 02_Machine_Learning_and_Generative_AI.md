# Machine Learning and Generative AI

## Introduction

Machine learning and generative AI are important areas within modern AI. This note introduces a few basic ideas about how systems learn from data and how generative tools create responses.

## Important Concepts

### 1. Data

Data is the information used by an AI system. It may include text, numbers, images, audio, or other examples.

**Example:** A collection of labelled pictures of cats and dogs can be used to train an image classifier.

### 2. Training and Inference

- **Training** is the process in which a model learns patterns from examples.
- **Inference** is when a trained model is used to produce an output for new input.

### 3. Models

A model is the part of an AI system that has learned patterns from data or has been configured to perform a task.

**Example:** An image model may receive a picture and predict whether it contains a cat or a dog.

### 4. Large Language Models

A Large Language Model (LLM) is an AI model trained to work with language. It can generate text, answer questions, summarise information, and help with writing.

### 5. Limitations of Generative AI

Generative AI can produce incorrect, incomplete, or misleading information. Its output should be checked, especially when accuracy matters.

## Practical Applications

- Classifying images or sorting information.
- Summarising documents.
- Drafting and improving written content.
- Answering questions about provided information.
- Supporting brainstorming and learning.

## My Understanding

AI models use data and learned patterns to produce outputs. Training is when a model learns, while inference is when it is used. Generative AI can be helpful for creating content, but its responses are not automatically correct and need human review.

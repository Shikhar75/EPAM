# Python Fundamentals

## Introduction

Python is a general-purpose programming language known for its readable syntax. It is used in automation, web development, data analysis, and artificial intelligence.

## Important Concepts

### 1. Variables

A variable is a name used to store a value.

```python
name = "Alex"
age = 20
```

Here, `name` stores text and `age` stores a number.

### 2. Common Data Types

Some common Python data types are:

- `int`: whole numbers, such as `10`
- `float`: decimal numbers, such as `3.14`
- `str`: text, such as `"Hello"`
- `bool`: either `True` or `False`

```python
is_learning = True
```

### 3. Operators

Operators perform actions on values.

```python
total = 10 + 5
is_greater = 10 > 5
```

Arithmetic operators include `+`, `-`, `*`, and `/`. Comparison operators include `==`, `!=`, and `>`.

### 4. Conditional Statements

Conditions let a program choose what to do.

```python
score = 75

if score >= 40:
    print("Pass")
else:
    print("Try again")
```

### 5. Loops

Loops repeat a block of code. A `for` loop is useful when going through a sequence, while a `while` loop repeats as long as a condition is true.

```python
for number in range(3):
    print(number)
```

## Practical Applications

- Automating repetitive tasks.
- Processing simple information.
- Writing small scripts and experiments.
- Building a foundation for learning data science and AI.

## My Understanding

Python lets me give instructions to a computer using readable code. Variables store information, data types describe the kind of information, conditions make decisions, and loops repeat actions.

# Introduction to Artificial Intelligence

## Introduction

Artificial Intelligence (AI) is a field of computing focused on creating systems that can perform tasks that usually require human-like abilities, such as recognising patterns, understanding language, or making recommendations.

## Important Concepts

### 1. What Is AI?

AI systems use data, rules, or learned patterns to produce outputs that help with a task.

**Example:** A map application may suggest a route based on traffic information.

### 2. Machine Learning

Machine Learning (ML) is a part of AI in which a system learns patterns from examples or data instead of relying only on manually written rules.

**Example:** An email service can learn to identify messages that look like spam.

### 3. Deep Learning

Deep Learning is a type of machine learning that uses structures called neural networks. It is useful for tasks such as image recognition and speech processing.

### 4. Generative AI

Generative AI creates new content, such as text, images, audio, or code, based on patterns learned from data.

**Example:** A text assistant can create a first draft of an email from a user's instructions.

### 5. AI in Everyday Life

AI is used in recommendation systems, voice assistants, translation tools, fraud detection, and navigation applications.

## Practical Applications

- Recommending films, music, or products.
- Helping detect unusual financial activity.
- Supporting translation and accessibility.
- Summarising text or generating first drafts.
- Assisting people with information search and analysis.

## My Understanding

AI is a broad field that helps computers perform useful tasks. Machine learning is one approach within AI, deep learning is one approach within machine learning, and generative AI focuses on creating content. These terms are related, but they do not mean exactly the same thing.

# AI Agent Tools and Workflows

## Introduction

AI agents can use tools and follow workflows to complete tasks. Understanding these parts helps explain how an agent can move from a user request to a useful result.

## Important Concepts

### 1. Tools

A tool is an external function or service an agent can use for a specific task.

**Example:** A calculator tool can perform arithmetic more reliably than asking a language model to calculate mentally.

### 2. Tool Selection

The agent or the system guiding it needs to choose a tool that matches the task.

**Example:** A search tool may be suitable for finding current information, while a calculator is suitable for arithmetic.

### 3. Workflow

A workflow is an organised sequence of steps.

A simple research workflow might be:

1. Understand the question.
2. Search an approved information source.
3. Review the results.
4. Summarise relevant information.
5. Present the answer.

### 4. Human Oversight

Some actions should be reviewed or approved by a person, especially if they affect other people, money, accounts, or important records.

### 5. Safety and Limitations

Agents can misunderstand instructions, use unsuitable information, or make mistakes. Tool access should be limited to what is necessary, and important results should be checked.

## Practical Applications

- Searching for information and preparing a summary.
- Organising a list of tasks.
- Checking calculations with a calculator.
- Drafting a response for human review.
- Supporting repeatable, multi-step office workflows.

## My Understanding

Tools give an agent ways to perform specific actions, while a workflow describes the steps used to complete a task. Human oversight and suitable permissions are important because an agent's actions and outputs may not always be correct.

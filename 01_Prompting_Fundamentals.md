# Prompting Fundamentals

## Introduction

A prompt is the instruction or input given to an AI model. Prompting is the process of writing instructions so that the model can better understand the task and produce a useful response.

## Important Concepts

### 1. Be Clear About the Task

A prompt should explain what the model is expected to do.

**Less clear:** `Tell me about Python.`

**Clearer:** `Explain what a Python variable is in simple language and give one short example.`

### 2. Provide Context

Context gives the model background information that can help it respond appropriately.

**Example:** `I am a beginner. Explain Git commits without assuming programming experience.`

### 3. Specify the Output Format

Mentioning the desired format can make the response easier to use.

**Example:** `Compare lists and tuples in a Markdown table.`

### 4. Set Boundaries

A prompt can specify length, tone, audience, or topics to avoid.

**Example:** `Explain this in five bullet points, using beginner-friendly language.`

### 5. Improve Prompts Iteratively

If the first response is not useful, adjust the prompt. Add missing context, clarify the task, or provide an example of the desired result.

## Practical Applications

- Asking for beginner-friendly explanations.
- Summarising notes in a specific format.
- Generating practice questions.
- Drafting outlines and checklists.
- Asking an AI assistant to compare concepts.

## My Understanding

A good prompt gives the AI a clear task and enough context to respond. I can improve results by specifying the audience, format, and boundaries. Prompting often involves trying, reviewing, and refining instructions.

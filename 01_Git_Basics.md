# Git Basics

## Introduction

Git is a version control system. It helps developers keep track of changes made to files over time. It is useful when working alone as well as when collaborating with other people.

## Important Concepts

### 1. Version Control

Version control records changes to files. It allows us to review earlier versions and understand what changed.

**Example:** If I edit a document and later remove an important paragraph, version control can help me find the earlier version.

### 2. Repository

A repository, often called a *repo*, is a folder whose changes are tracked by Git. It contains project files and Git's history.

### 3. Commit

A commit is a saved checkpoint of the changes made to a repository. A commit usually includes a short message describing the changes.

```bash
git commit -m "Add introductory notes"
```

### 4. Branch

A branch is a separate line of work. It lets someone make changes without immediately changing the main line of work.

```bash
git branch notes-update
```

### 5. Git and GitHub

Git is the version control tool that runs on a computer. GitHub is an online platform where Git repositories can be hosted and shared.

## Practical Applications

- Keeping a history of changes to study notes or code.
- Trying changes on a separate branch.
- Collaborating with classmates.
- Sharing a portfolio through GitHub.

## My Understanding

Git helps me manage changes instead of keeping many confusing copies of the same files. A repository stores the work, commits save checkpoints, and branches help organise separate changes. GitHub makes it easier to store and share Git repositories online.
